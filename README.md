## :dart: O guia para alavancar a sua carreira

> Kotlin é a linguagem oficial para desenvolvimento Android desde 2019 e roda em qualquer lugar que a JVM roda: back-end com Spring Boot e Ktor, scripts de automação e, com Kotlin Multiplatform, também em iOS, web e desktop a partir da mesma base de código. Criada pela JetBrains e hoje desenvolvida com participação ativa do Google, ela une sintaxe concisa, null safety verificada em tempo de compilação e interoperabilidade total com Java. Este guia reúne roadmap, documentação oficial, cursos gratuitos e pagos, livros, canais, ferramentas, comunidades e um capítulo dedicado a usar IA na prática com Kotlin — tudo verificado e organizado para quem já programa e quer sair do primeiro `fun main()` até um app Android ou uma API em produção.

## 💡 Nossa proposta

> A proposta deste guia é dar uma ideia sobre o atual panorama e guiá-lo se você estiver confuso sobre qual será o seu próximo aprendizado, sem influenciar você a seguir os 'hypes' e 'trends' do momento. Acreditamos que com um maior conhecimento das diferentes estruturas e soluções disponíveis poderá escolher a ferramenta que melhor se aplica às suas demandas. E lembre-se, 'hypes' e 'trends' nem sempre são as melhores opções.

## :beginner: Para quem está começando agora

> Não se assuste com a quantidade de conteúdo apresentado neste guia. Acredito que quem está começando pode usá-lo não como um objetivo, mas como um apoio para os estudos. <b>Neste momento, dê enfoque no que te dá produtividade e o restante marque como <i>Ver depois</i></b>. Ao passo que seu conhecimento se torna mais amplo, a tendência é este guia fazer mais sentido e ficar fácil de ser assimilado. Bons estudos e entre em contato sempre que quiser! :punch:

## 🛠️ Ferramentas

> Editores, IDEs e execução

- [IntelliJ IDEA](https://www.jetbrains.com/idea/) — IDE oficial da JetBrains para Kotlin/JVM, com a versão Community gratuita.
- [Android Studio](https://developer.android.com/studio) — IDE oficial do Google para desenvolvimento Android, baseada no IntelliJ e com Kotlin como linguagem padrão.
- [Kotlin Playground](https://play.kotlinlang.org/) — Editor online oficial: rode e compartilhe trechos de Kotlin sem instalar nada.

> Build, qualidade de código e documentação

- [Gradle Kotlin DSL](https://docs.gradle.org/current/userguide/kotlin_dsl.html) — Referência oficial da sintaxe Kotlin para configurar builds Gradle (`build.gradle.kts`).

## 🤖 IA na prática

Kotlin tem um aliado natural nos assistentes de IA: o **null safety e o sistema de tipos do compilador** rejeitam boa parte do código malformado antes mesmo de rodar, o que torna mais fácil perceber quando uma sugestão de IA está errada.

**Para aprender**
- Cole um erro do compilador (ex.: `Type mismatch: inferred type is String? but String was expected`) e peça para a IA explicar a causa e mostrar a forma idiomática de resolver (`?:`, `let`, `requireNotNull`) em vez de usar `!!` cegamente.
- Peça para **converter uma classe Java para Kotlin idiomático** e depois explicar cada mudança (data class, propriedades, null safety).
- Peça **exercícios com gabarito** sobre o tópico que está estudando (coroutines, sealed classes, extension functions) e resolva no [Kotlin Playground](https://play.kotlinlang.org/).
- Peça para revisar uma solução dos [Kotlin Koans](https://kotlinlang.org/docs/koans.html) e sugerir uma versão mais idiomática.

**Para trabalhar**
- Use o [JetBrains AI Assistant](https://www.jetbrains.com/ai/) direto no IntelliJ IDEA/Android Studio: ele entende o contexto do projeto Kotlin/Gradle e sugere refatorações específicas da linguagem.
- [GitHub Copilot](https://github.com/features/copilot), [Cursor](https://cursor.com/) e [Claude Code](https://code.claude.com/docs/en/overview) ajudam a escrever testes com Kotest/MockK, gerar `data class`es a partir de um JSON de API e migrar código Java → Kotlin arquivo a arquivo.
- Depois de **cada** sugestão aceita, rode o build (`./gradlew build`) e o `detekt`/`ktlint`. Se o código só compila com `!!` ou `as?` sem tratamento, a sugestão provavelmente está errada.

**Limites e boas práticas**
- IA **inventa nomes de funções e assinaturas** de bibliotecas Kotlin, principalmente em APIs recentes como Kotlin Multiplatform e Compose. Confirme sempre na documentação oficial.
- Ela tende a usar `!!` para "resolver" erros de nulidade rapidamente — isso normalmente esconde um bug em vez de corrigi-lo.
- Não cole código proprietário, segredos ou dados de clientes em ferramentas sem a política da sua empresa.

**Kotlin também está entrando na construção de sistemas de IA:**
- [Koog](https://github.com/JetBrains/koog) — Framework open source da JetBrains, 100% Kotlin, para construir agentes de IA.
- [MCP Kotlin SDK](https://github.com/modelcontextprotocol/kotlin-sdk) — SDK oficial para criar servidores e clientes do Model Context Protocol em Kotlin.
- [LangChain4j](https://github.com/langchain4j/langchain4j) — Framework para aplicações com LLMs na JVM, totalmente utilizável a partir do Kotlin.
- [Spring AI](https://spring.io/projects/spring-ai) — Módulo do Spring para integrar LLMs em aplicações Spring Boot, inclusive as escritas em Kotlin.
